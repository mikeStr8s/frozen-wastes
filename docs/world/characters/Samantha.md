# Samantha

_Shop assistant, the Musical Empolardium_

[Polard Hinscrop](Polard%20Hinscrop.md)'s hired help at his rebuilt [Easthaven](../atlas/Easthaven.md) instrument shop — the first employee in the long and fraudulent history of the [Music Shop Conspiracy](../organizations/Music%20Shop%20Conspiracy.md), and the end of any practical need for the two-gnome charade.

She was working the counter when the party arrived to find the new shop bigger than the old one and about half finished. They suggested a better name for the place, a pun, and Polard did not need to think about it.

> "Samantha, we need to change the sign immediately."

So it was the **[Musical Empolardium](../atlas/Musical%20Empolardium.md)**.
